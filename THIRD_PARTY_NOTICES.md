# Avisos de terceros

## Stockfish.js 19.0.1

Motor de ajedrez de código abierto distribuido bajo GNU General Public License v3.0 (GPL-3.0). Proyecto original y fuente: https://github.com/nmrugg/stockfish.js

El motor se instala desde el paquete npm `stockfish@19.0.1`. Durante la compilación, `scripts/copy-engine.mjs` copia `stockfish-19-single.js` y `stockfish-19-single.wasm` a los recursos de la aplicación. Si el paquete npm incluye el archivo de licencia, se copia también como `STOCKFISH-LICENSE.txt`.
